# CS50 AI with Python

Solutions and implementations from Harvard's CS50 Introduction to Artificial Intelligence with Python.

## Projects

### Degrees
Search algorithm to find the shortest connection path between actors using breadth-first search.

### Minesweeper
AI agent using knowledge representation and logical inference to play Minesweeper.

### PageRank
Implementation of Google's PageRank algorithm using random walks and Markov chains.

### Heredity
Bayesian inference model for predicting genetic inheritance probabilities.

### Shopping
K-nearest neighbors classifier predicting online shopping revenue.

### Nim
Reinforcement learning agent trained through Q-learning.

### Traffic
Convolutional neural network for traffic sign classification.

### Parser
Natural language parser using context-free grammars.

### Crossword
Constraint satisfaction solver using arc consistency and backtracking.
